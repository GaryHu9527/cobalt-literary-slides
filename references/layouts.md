# 构图与内容规则

样稿：2026-10-22用户确认的《当经典不再令人惊艳》35页版本。以下是版式词汇，不是新稿固定页序。

| 用途 | 基准页 / 预览 | 可复用结构 |
|---|---|---|
| 封面 | 01-cover | 左侧两行宋体大字，低位副标题，右侧较大mono图，整体不贴顶部 |
| 观众提问 | 02-question | 内容位于页面中部，两级字号，居中，不增添虚构答案与比例 |
| 章节转场 | 04-chapter | 大号钴蓝宋体位于中部偏左，右下小型题意插画，右上线束 |
| 作品背景 | 05-book | 标题左上但留足上边距；真实书封与可读的叙述块并置；版本短说明 |
| 并列比较 | 07-table | 原生3列表格，蓝色表头、纸白表体、细边线；两部作品视觉权重相同 |
| 单位人物 | 15-author | 两行标题在左，人物大肖像在右，从底部切入；非图标尺寸 |
| 人物群像 | 16-gallery | 一行同尺寸真实照片，姓名为原生文字；图片数量按内容决定 |
| 双人论述 | 20-pair | 两个大姓名与两幅肖像，下缘切入，留出中间呼吸区 |
| 概念论述 | 23-context | 一句清楚的大标题，少量完整段落，靠分段建立节奏，不套卡片 |
| 文本细读 | 26-reading | 一个具体问题、与文本有关的图片、两层论证；关键判断另成清晰一行 |
| 文献 | 34-references | 两栏左对齐、小字号例外，完整条目，细竖线；不塞进正文页角落 |
| 结尾 | 35-ending | “谢谢聆听”大字、“欢迎交流”小字、右下mono图、短横线及角部线束 |

## 变化原则

- 概念问题可纯文字；背景、人物和作品适合图文并置；证据靠文本细节，不能为了有图而压小证据文字。
- 图片页约占画面20%–45%可作为起点，封面和人物页可更大。小型章节插画是配角，不要求每页同等面积。
- 长句不要一味放大并横穿整页；按语意主动断行。两行标题通常使用接近的句法长度，避免最后孤立一两个字。
- 相邻页不同构图应服务内容；连续比较页则保持同轴对齐。
- 不凭空新增作者评价、年代、引文与文学史结论。原文引文和演讲者解释有明确区别；未核对的引文不能套引号冒充原文。
- 用户强调“不要简略成这样”：要保留具体证据和真正的论证，不把所有页都缩成一句口号。
