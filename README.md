# 钴蓝人文演讲 PPT

复用已确认的纸白、钴蓝、宋黑字体、真实书封与作家照片、mono 插画和细线装饰，制作可编辑的演讲 PPT。

## 使用

将本仓库作为 Codex skill 安装到 skills/cobalt-literary-slides，然后输入：

> 使用 $cobalt-literary-slides，按以下新内容制作演讲 PPT，沿用已定稿的视觉风格。

[完整复用提示词](references/reuse-prompt.md) · [技能说明](SKILL.md) · [设计参数](references/design-system.json)

## 最终基准稿

- [35 页可编辑 PPTX](assets/reference-deck.pptx)
- [PDF 预览](examples/final-deck.pdf)
- [代表页预览](assets/previews/)

第 7 页是作品比较表，第 34 页是参考文献，第 35 页是感谢页。

这套技能复用视觉系统，不固定新演讲的主题、内容或页数。书封、照片与插画是示例稿内容素材，来源说明见对应页备注；新稿应使用与新主题相符的素材。本仓库不对第三方书封和照片授予额外授权。
